# Brainstorming Skill

When tasked with creating or modifying a feature, especially UI components or complex logic, apply the following brainstorming framework before writing code:

## 1. Understand the Goal
- What is the primary objective of the user?
- What is the underlying aesthetic or functional requirement (e.g., Windows 98 retro theme, high-performance API)?

## 2. Identify Edge Cases
- What happens if the data is empty?
- How does the UI behave on mobile vs desktop?
- What are the accessibility implications?

## 3. Creative Ideation (The "Wah" Factor)
- How can we make this feature delightful?
- Are there micro-interactions, animations, or specific design languages (like etched 3D borders for Win98) that elevate the experience?
- Propose at least two different approaches and select the best one.

## 4. Execution Plan
- Outline the files to be modified.
- Outline the state management required.
- Proceed to implementation only when the mental model is clear.
