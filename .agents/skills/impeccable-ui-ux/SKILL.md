# Impeccable UI/UX Skill

When designing or modifying frontend components, ensure the result is not just functional, but impeccable and impressive.

## 1. Thematic Consistency
- Strictly adhere to the established design language (e.g., Windows 98 Retro).
- Do not mix modern design paradigms (e.g., soft shadows, rounded corners, flex-wrap gaps without structure) with retro themes unless explicitly requested.
- For Win98: Use system colors (`#c0c0c0`, `#000080`), 3D inset/outset borders (`border-t-white border-l-white border-b-black border-r-black`), and pixelated typographies.

## 2. Layout & Alignment
- Ensure perfect padding and margin alignment.
- Prevent awkward overflows or empty scrollable areas. Containers should wrap their content snugly or expand gracefully.
- Use structured layouts (e.g., Data Grids, Fieldsets, Tree Views) for displaying complex data like work experience or tech stacks.

## 3. Micro-interactions
- Buttons must have clear active/pressed states (e.g., inset borders, shifting text 1px down-right).
- Interactive elements must clearly signal their state (hover, disabled, focused).

## 4. Polish
- Remove unnecessary scrollbars.
- Ensure text contrast is accessible.
- If an element feels "boring", brainstorm ways to make it thematic (e.g., turning a simple list into a Windows 98 file explorer view).
